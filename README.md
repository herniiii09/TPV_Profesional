# TPV_Profesional
Tras pensar en miles de empresas que pagan por un TPV, me he decido por realizar un proyecto de código libre, gratuito y totalmente solidario. Este esta desarrollado en lenguaje HTML por lo que es tan sencillo como descargarlo, acceder como el usuario administrador y configurar productos, usuarios... He decidido añadirle en el momento de realizar las ventas, si se ha recibido el pago en efectivo (en este caso, introduces la cantidad recibida y la web te devuelve cuanto dinero tienes que darle al cliente) o por tarjeta, que todas las compras queden registradas y en cualquier momento puedas descargar en un documento PDF todas las compras que haya habido en cualquier día. Con este proyecto quiero mostrar todo mi apoyo hacia PYMEs y Autónomos, sin ellos la gran mayoría de nosotros no tendría trabajo.
